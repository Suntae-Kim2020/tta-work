# HL7 FHIR (의료 데이터 교환)

- **문서**: https://hl7.org/fhir/
- **코드**: https://hl7.org/fhir/downloads.html
- **방식**: 스펙 전체가 기계처리 가능한 리소스 정의에서 생성. HTML 문서와 JSON/XML/XSD/RDF 산출물이 하나의 빌드에서 함께 나옴.

## 확보 내역

R5 definitions(JSON·XML), fhir-all-xsd(XSD 323개), JSON Schema, ShEx, GraphQL, RDF/TTL. ※ PDF의 'definitions.shex.zip'은 실제 파일명이 fhir.schema.shex.zip.

## 파일 목록 (총 9개)

- `문서_fhir-downloads.html`
- `문서_fhir-r5-index.html`
- `코드_definitions.json.zip`
- `코드_definitions.xml.zip`
- `코드_fhir-all-xsd.zip`
- `코드_fhir.rdf.ttl.zip`
- `코드_fhir.schema.graphql.zip`
- `코드_fhir.schema.json.zip`
- `코드_fhir.schema.shex.zip`
