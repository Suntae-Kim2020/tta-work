# Schema.org

- **문서**: https://schema.org/docs/developers.html
- **코드**: https://github.com/schemaorg/schemaorg
- **방식**: 어휘를 GitHub의 Turtle 소스로 유지하고, 릴리스마다 HTML 용어 페이지와 기계가독 덤프(JSON-LD·Turtle·RDF/XML·N-Triples·CSV)를 자동 생성.

## 확보 내역

latest 덤프 6종 + 저장소(규범 소스 data/schema.ttl, docs/, software/ 빌드도구, 최신 릴리스 30.0). ※ 저장소 원본은 약 2GB(과거 릴리스 아카이브)라 최신 릴리스 1개만 남기고 101MB로 정리.
