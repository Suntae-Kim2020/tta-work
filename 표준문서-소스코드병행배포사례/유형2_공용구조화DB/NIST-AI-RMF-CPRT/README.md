# NIST AI RMF 1.0 (공용 구조화 DB)

- **문서**: https://airc.nist.gov/airmf-resources/airmf/
- **코드**: https://csrc.nist.gov/projects/cprt/catalog
- **방식**: 산문 프레임워크를 PDF로 발간하고, 구조화 콘텐츠(기능·카테고리·서브카테고리)를 CPRT에 별도 등재. 여러 문서 표준을 단일 기계가독 스키마로 통합 제공.

## 확보 내역

AI RMF 1.0(AI_100_1_0_0) JSON·XLSX·graph 내려받음. CSF 2.0을 함께 받아 대조한 결과 두 프레임워크가 documents·elements·relationship_types·relationships 라는 동일 스키마를 사용함을 실증(AI RMF: 요소 1,960/관계 1,956, CSF 2.0: 906/1,566). CPRT 전체 메타데이터에는 209개 프레임워크 버전이 등재.
