## 핵심 구조

```
제안자 ──── 요소 정의표 ①~⑬ 작성
공동 에디터 ─ ⑭ 전역 어휘 식별자(IRI) 매핑 + 기계가독 부속서 보강
             (운영규정 제29조①2 특별위원 · 제33조⑤ 의결권 없음)
산출물 ───── @context 부속서 (표준 문서 내)
```

**신설 조문**: 운영요령 제19조의2제5항(공동 에디터)
**운영규정**: 개정 불요 — 기존 조문을 근거로 활용(제57조 위임)

## 방법1과의 차이

| | 방법2 | 방법1 |
|---|---|---|
| 어휘 매핑 주체 | **공동 에디터**(어휘 전문가) | 제안자(에디터) |
| 산출물 위치 | @context 부속서(문서 내) | 부속서 내장형 **또는** 외부 참조형 |
| 산출물 범위 | 요소↔IRI 매핑 | 스키마 + 참조구현(선택) |
| 신설 조문 | 제19조의2제5항 | 제19조의3 |
| 품질 보증 | 전문가 검증 | 제안자 자기선언 + 형식 자동 점검 |

비교 상세는 [../AI-Ready_방법1_제안자선언형/보고서용/방법1_방법2_비교표.md](../AI-Ready_방법1_제안자선언형/보고서용/방법1_방법2_비교표.md) 참조.
