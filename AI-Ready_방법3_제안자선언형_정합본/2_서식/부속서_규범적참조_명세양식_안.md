# [부속서 양식(안)] 기계가독 산출물 — 규범적 참조 명세

작성지침 6.6 b)(참조형)에 따라 표준초안의 부속서로 작성한다.
산출물 분량이 많거나, 표준 문서와 다른 주기로 개정되거나, 다른 파일을 인용·포함하여 단일 파일로 완결되지 아니하는 경우에만 사용하며, **병행형(6.6 a)이 원칙**이다.

> **부속서 번호는 고정하지 아니한다.** 아래 예시는 부속서 X로 적었다. 실제 번호는 작성지침 6.6의 **A, B, C 순 부여 원칙**에 따르며, 기계가독 산출물이라 하여 특정 알파벳을 지정하지 않는다. 이미 부속서를 가진 표준이라면 그다음 알파벳이 된다.

## 부속서 X 기계가독 산출물

**(본 부속서는 표준 내용의 일부임)**

### X.1 규범성

이 부속서가 지정하는 기계가독 산출물은 본 표준의 규범 내용이다. 산출물에 적합하지 아니한 구현은 본 표준에 적합하다고 할 수 없다.

## 작성 시 유의사항

**하나.** 버전과 무결성 확인 값을 반드시 적는다. 외부 저장소는 변경될 수 있으므로, 이 두 값이 "표준이 지정한 그 산출물"을 특정한다.

**둘.** 파일명에 버전을 넣는 규칙을 권장한다(예: `mods-3-8.xsd`). 파일명이 바뀌면 문서의 링크가 깨진다. 국제 사례에서 HL7 FHIR의 `definitions.shex.zip`이 `fhir.schema.shex.zip`으로 바뀌어 기존 문서의 링크가 무효가 된 사례가 확인됐다.

**셋.** 이용조건은 이 명세뿐 아니라 **산출물 파일 자체에도** 표시한다(작성지침 6.6).

**넷.** 항목 번호는 작성지침 5.3.3·6.8.1 e)의 체계(`a) → 1) → (a) → (1) → (가)`)를 따른다. 원문자(①②③)는 쓰지 아니한다.
