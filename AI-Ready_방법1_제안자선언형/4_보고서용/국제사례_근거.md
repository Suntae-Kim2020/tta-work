# 방법1을 뒷받침하는 국제 사례 근거

근거 자료: 상위 폴더 `표준문서-소스코드병행배포사례/` (16개 사례 실물 수집 273MB, 2026-08-14 검증)

## 1. 방법1의 각 설계 판단과 대응 사례

| 방법1 설계 | 근거 사례 | 확인 내용 |
|---|---|---|
| 제안자가 스키마까지 제공 | NIST OSCAL, CycloneDX, SPDX | 스키마가 규범이고 문서가 파생물. 개발 주체가 스키마를 직접 관리 |
| 스키마를 GitHub에 공개 | Schema.org, Croissant, SPDX, CycloneDX | 저장소가 곧 배포 경로. 문서와 스키마가 한 커밋으로 함께 변경 |
| 협회 보관본을 정본으로 | **CycloneDX** | GitHub 배포 + 같은 버전을 Ecma가 ECMA-424 정식 판으로 승인하는 이중 트랙 |
| 명세형 부속서(규범적 참조) | **ECMA-424** | 566쪽 본문에 스키마 코드가 없고 GitHub를 규범적으로 참조 |
| 라이선스를 파일 자체에 표시 | LoC METS, DDI 3.3, CycloneDX | XSD 주석·JSON `$comment`·`dcterms:license` 트리플 |
| 참조구현을 표준에서 배제 | Schema.org | 빌드 도구(Apache-2.0)와 어휘(CC BY-SA)를 명시적으로 분리 |

## 2. 심의에서 쓸 수 있는 실측 결과

### 2-1. 표준 문서에 스키마를 담은 사례는 0건

PDF 3종(ECMA-424 2판, NIST AI 100-1, PREMIS Data Dictionary)을 압축 스트림까지 풀어 검사한 결과, 스키마 본문도 PDF 첨부파일(EmbeddedFile)도 없었다.

**의의**: 방법1의 명세형 부속서가 국제 관행에 부합함을 보인다. 분량이 이유다 — HL7 FHIR은 XSD 323개, ISO 19115-3은 117개다.

### 2-2. 제공 방법은 여덟 가지이며, 성숙한 표준은 조합해 쓴다

| 제공 방법 | 사례 |
|---|---|
| 표준 문서 내 포함 | **없음** |
| 같은 웹 디렉터리 병행 게시 | LoC PREMIS·MODS·METS, DDI |
| 전용 스키마 저장소 사이트 | OGC, ISO 19115-3 |
| 네임스페이스 URI 역참조 | W3C DCAT·PROV-O, DCMI |
| GitHub 릴리스 자산 | OSCAL, CycloneDX |
| GitHub 저장소 자체 | Schema.org, Croissant, SPDX |
| 전용 다운로드 페이지 | HL7 FHIR |
| 구조화 DB + REST API | NIST CPRT |

### 2-3. ISO조차 스키마는 무료 공개한다

ISO 19115-3은 문서 본문을 유료 판매하면서 규범 XSD 117개를 `standards.iso.org`에 무료 공개한다(일괄 zip 10.4MB 확인).

**의의**: 유료 문서 체계 안에서도 스키마 개방이 성립한다.

### 2-4. 라이선스 표기 방식이 형식마다 다르다

| 형식 | 주석 | 실제 표기 |
|---|---|---|
| XSD | 가능 | CycloneDX: Apache-2.0 전문을 머리말에 삽입 |
| JSON Schema | **불가** | CycloneDX: `$comment` 키 활용 |
| RDF 어휘 | 가능 | W3C DCAT: `dcterms:license` 트리플 (**기계가독 선언**) |

**의의**: 작성지침 6.6의 형식별 표기 규정이 여기서 나왔다.

### 2-5. 라이선스 미표기가 실제 장애물이다

ISO 19115-3의 XSD 117개에는 저작권·라이선스 문구가 **하나도 없다**. 이용약관 페이지는 봇 차단으로 접근이 막힌다. 무료 공개하면서도 이용자가 재배포 가능 여부를 알 수 없는 상태다.

**의의**: 운영요령 제19조의3제7항(라이선스를 파일 자체에서 확인 가능하게 표시)의 직접 근거다.

## 4. 라이선스 갈래 (방법1의 라이선스 규정 근거)

| 갈래 | 라이선스 | 사례 |
|---|---|---|
| 소프트웨어 라이선스 | Apache-2.0, BSD-3-Clause | FHIR, CycloneDX, Croissant |
| 문서·콘텐츠 라이선스 | CC BY 4.0, CC BY-SA 3.0 | DDI 3.3, DCAT, DCMI, Schema.org(어휘) |
| 퍼블릭 도메인 | CC0 1.0, 미국 정부 저작물 | OSCAL, AI RMF, LoC METS |

**"스키마는 코드인가 문서인가"에 대한 국제적 합의는 없다.** 방법1은 이 판단을 규정에서 강제하지 않고, **제안자가 이용조건을 선언하되 파일에 표시하도록** 의무화하는 방식을 택했다. 어느 갈래를 택하든 이용자가 확인할 수 있으면 목적이 달성되기 때문이다.
