- **문서**: https://www.iso.org/standard/80874.html
- **코드**: https://standards.iso.org/iso/19115/-3/
- **방식**: 개념 모델·스펙 본문은 유료 판매하되, 규범 XSD는 standards.iso.org 공개 저장소에 무료 게시. ISO 체계 안에서도 스키마 무료 공개가 성립함을 보여주는 사례.

## 확보 내역

19115AllNamespaces.zip(공식 일괄 배포본, XSD 117개) + mdb 2.0 진입점 XSD. ※ 문서 페이지(iso.org)는 유료·봇 차단(Cloudflare)이라 본문 미수집 — 이 대비 자체가 '문서 유료 + 스키마 무료' 구조의 증거.
