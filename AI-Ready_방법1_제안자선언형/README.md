# AI-Ready 표준화 방법1 — 제안자 선언형

**표준 제안자가 어휘를 선언하고 기계가독 산출물(스키마)까지 제공하는 구조.** 협회는 별도의 어휘 전문가를 배정하지 않는다.

> 이 문서군은 **방법2(공동 에디터 보강형)와 별개의 독립 개정안**이다. 현행 규범을 기준으로 작성했으며 방법2를 참조하거나 전제하지 않는다. TTA 보고서에서는 두 방법을 함께 제안한다.

## 핵심 설계

**1. 스키마는 규범이다.** 참고 자료가 아니다. 따라서 부속서 수록(또는 규범적 참조), 지식재산권 확인, 협회 보관, 라이선스 명시가 모두 따라 나온다.

**2. 외부 공개를 허용하되 보관본이 정본이다.** GitHub 등에 공개할 수 있으나, 협회가 채택 시점 사본을 보관하고 외부 공개본과 다르면 보관본에 따른다. CycloneDX가 GitHub 배포와 Ecma 정식 승인을 병행하는 구조와 같다.

**3. 참조구현 코드는 표준이 아니다.** 위치를 부록에 안내할 수 있을 뿐이며 협회는 보증하지 않는다.

### 별표 10·별지 제21-1호는 방법1용으로 별도 작성이 필요하다

이 문서군에는 별표 10(수준 요건)과 별지 제21-1호(자가점검표)의 세부 내용을 포함하지 않았다.

기존 작업물(`../AI-Ready_방법2_공동에디터보강형/AI-Ready_수준요건_명세서_v0.3.docx`, `AI-Ready_자가점검표.docx`)을 그대로 쓸 수 없다. 문서 본문이 **공동 에디터를 전제**하고 있기 때문이다(수준요건 명세서 10회, 자가점검표 4회 언급 확인).
