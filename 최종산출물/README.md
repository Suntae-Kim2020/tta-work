**09·10 통합본의 원문은 PDF에서 추출한 것**이다. 운영요령은 줄바꿈이 낱말 가운데를 가른 곳을 원문과 대조해 바로잡았으나, 의결 전 원본 PDF로 최종 대조가 필요하다. 생성 도구는 `도구/build_consolidated.py`.

## 읽는 순서

1. **00 개요**로 구조를 잡는다. 제안자 선언 → 에디터 작성 → 협회 보관, 병행형 원칙·참조형 예외, 참조구현 배제.
2. **01 운영요령 개정안**이 본체다. 제19조의3(10개항)이 핵심 조문이고, 별표 10과 별지 서식 3종 신설·3종 개정이 여기서 위임된다.
3. **03~06**은 01이 신설·개정하는 별표·별지의 실물이다.
4. **02 작성지침 개정안**은 01이 의결된 뒤 상정한다. 작성지침이 운영요령 제19조의3을 참조하기 때문이다.
5. **07**은 02의 6.6 b)가 정하는 참조형 부속서의 양식이다.
6. **08**은 "운영규정을 왜 고치지 않는가"라는 심의 질문에 대한 답이다.

## 문서 안의 해설에 대하여

신구조문대비표 아래의 해설(인용 표시 문단)은 심의에서 나올 질문에 미리 답한 것이다. 공식 상정 문서에서 해설을 뺀 판이 필요하면 정본에서 인용 블록을 제외하고 다시 생성한다.

## 의결 전 확인할 것

- 현행 문안은 PDF 추출본을 조문 단위로 대조한 것이다. **의결 전 원본 PDF로 최종 대조**가 필요하다.
- 작성지침의 최신 판번호(TTAR-09.0040/R1 이후 개정 여부)는 TTA 사무국 확인이 필요하다.
- 운영요령 문서번호 표기(`SBG-0030/R13`)는 원본 표지 확인 후 확정한다.
- 별지 제15·23·24호서식은 추가 문안을 정한 것이며, 한글 양식 파일에 칸을 그려 넣는 편집은 사무국 선례에 따른다.

## 웹에서 내려받기

같은 파일을 GitHub Pages에서도 내려받을 수 있다 — https://suntae-kim2020.github.io/tta-work/downloads.html (상단 메뉴 「최종산출물」). 웹용 사본은 `docs/downloads/`에 있으므로, 이 폴더의 HWPX를 다시 생성하면 `docs/downloads/`에도 복사해야 한다(도구: scratchpad `build_downloads.py`, 또는 수동 복사). 같은 페이지 아래쪽의 「파일럿 실증 5종 — 제안패키지」 표는 `AI-Ready_방법3_제안자선언형_정합본/4_제안패키지/`의 HWPX와 부속서 ZIP(`docs/downloads/제안패키지/`)을 내려받게 한다. 패키지를 다시 만들면 `4_제안패키지/도구/build_downloads.py`로 웹 사본도 다시 만든다.

## 생성 방법

```
python md2hwpx.py <정본.md> <출력.hwpx> [문서 제목]
```

생성 스크립트는 `도구/md2hwpx.py`에 있다. 틀(header.xml 스타일)은 `AI-Ready_방법1_제안자선언형/4_보고서용/스키마와_참조구현_결정기준.hwpx`에서 가져온다.
